# Housing — Regresión Lineal vs SVR

Notebook para Google Colab y GitHub.

## Objetivo
Predecir el valor medio de las viviendas del dataset California Housing usando:
- Regresión Lineal
- SVR (Support Vector Regression) con kernel lineal

## Flujo
1. Importar librerías
2. Cargar Housing
3. Separar X e y
4. Dividir 80/20
5. Estandarizar
6. Entrenar modelos
7. Predecir
8. Evaluar con R² y RMSE

El código principal está limitado a 26 líneas numeradas y cada línea está comentada para facilitar la explicación oral.
